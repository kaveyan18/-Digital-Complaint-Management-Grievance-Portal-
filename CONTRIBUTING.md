# Contributing to ResolveDesk

Thank you for your interest in contributing to ResolveDesk! We welcome contributions from the community to make this project even better.

## code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## How to Contribute

1.  **Fork the Repository**: accessible via the GitHub interface.
2.  **Clone the Fork**: `git clone https://github.com/YOUR_USERNAME/resolve-desk.git`
3.  **Create a Branch**: `git checkout -b feature/amazing-feature`
4.  **Make Changes**: Implement your feature or fix.
5.  **Test**: Run `npm test` in both backend and frontend directories.
6.  **Commit**: `git commit -m "Add amazing feature"`
7.  **Push**: `git push origin feature/amazing-feature`
8.  **Open a Pull Request**: Submit your changes for review.

## Reporting Bugs

If you find a bug, please create an Issue on GitHub with:
-   Description of the bug
-   Steps to reproduce
-   Expected behavior
-   Screenshots (if applicable)

## Feature Requests

We love new ideas! If you have a suggestion, open an Issue with the "Enhancement" label.
